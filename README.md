# 🎮 V1 OFFICIALS – Free Fire Tournament Website

V1 OFFICIALS is an online Free Fire tournament registration and management website where players can participate in Solo, Duo, and Squad tournaments.

## 🚀 Features

- Player registration and login
- User authentication
- Tournament dashboard
- Solo, Duo, and Squad tournament modes
- Tournament entry fee and prize pool details
- Tournament registration system
- Free Fire Player UID collection
- Mobile number validation
- Team name and teammate details
- Tournament rules acceptance
- Payment integration development
- Admin dashboard
- Registration management
- Tournament room details
- Results management
- Tournament creation

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend & Database
- Supabase
- PostgreSQL
- Supabase Authentication
- Supabase Edge Functions

### Payment Integration
- Razorpay API (integration development)

### Tools & Platforms
- Visual Studio Code
- Git
- GitHub
- Supabase Dashboard
- Cloudflare Pages / Web Hosting

- `tournament_payments`

## ⚙️ Setup Instructions

1. Clone the repository:

```bash
https://github.com/vishnuballa35-byte/tounament
```

2. Open the project folder in VS Code.

3. Configure your Supabase project URL and public anon/publishable key.

4. Open the HTML files using Live Server.

## 🎯 Project Objective

The main objective of V1 OFFICIALS is to provide an easy-to-use platform for organizing Free Fire tournaments, managing player registrations, handling tournament information, and displaying match results.
